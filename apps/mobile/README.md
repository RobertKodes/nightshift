# NIGHTSHIFT mobile (apps/mobile)

The Android owner app: run your AI companies from your phone. Expo SDK 58, React Native, expo-router.

It sits outside the pnpm workspace on purpose (`!apps/mobile` in pnpm-workspace.yaml, and in .dockerignore), so the engine image never installs React Native. It has its own npm lockfile.

## Build

```bash
npm install
npm run typecheck
bash scripts/build-debug.sh            # x86_64 debug APK for the emulator (add --clean after changing app.config.ts or plugins)
bash scripts/build-release.sh          # signed AAB for Play; needs the upload-key env vars listed in the script
```

`scripts/env.sh` points the build at the Android SDK already on this PC (`NIGHTSHIFT_ANDROID_HOME` overrides it) and at JDK 21.

`android/` is generated by `expo prebuild` and is not committed. Change native behaviour in `app.config.ts` and `plugins/`.

## Native pieces

- `modules/device-key`: an Android Keystore P-256 key that signs only after a strong biometric check (BiometricPrompt + CryptoObject). Signatures are base64 DER (SHA256withECDSA); public keys are base64 SPKI.
- Reown AppKit (`src/wallet/appkit.ts`) for wallet sign-in. Swaps, on-ramp and social logins are off (Play payments policy).
- `google-services.json` (gitignored) turns on FCM push when it is present at build time.
